# ⚙️ How to Run the Project

## Step 1 – Open the Workbook

Open the Excel workbook containing the sales dataset.

## Step 2 – Enable Macros

Make sure Excel macros are enabled.

## Step 3 – Open VBA Editor

Press:

```text
Alt + F11
```

## Step 4 – Insert a Module

In the VBA Editor, select:

```text
Insert → Module
```

## Step 5 – Paste the VBA Code

Paste the complete VBA code into the module.

## Step 6 – Run the Main Macro

Run:

```text
BuildCompleteSalesDashboard
```

The macro will create the required dashboard components.

### Automatically Created Components

* Pivot Tables
* KPI Cards
* Charts
* Year Slicer
* Month Slicer
* Refresh Dashboard Button
* Dashboard Formatting

---

# 🔄 Updating the Dashboard

When the underlying data is updated:

1. Update the `Data` worksheet.
2. Open the `Dashboard` worksheet.
3. Click **Refresh Dashboard**.
4. Review the updated KPIs and charts.
5. Use the **Year** and **Month** slicers to perform filtered analysis.
